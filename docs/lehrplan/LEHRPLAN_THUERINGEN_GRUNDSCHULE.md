# Lehrplan Thüringen Grundschule – Arbeitsfassung für Codex

Diese Datei ist eine projektinterne Arbeitsfassung auf Basis der bereitgestellten Lehrplan-PDFs. Sie ersetzt nicht die Original-PDFs. Für fachliche Details und vollständige verbindliche Formulierungen sind die PDF-Quellen in `docs/lehrplan/quellen/` maßgeblich.

## App-Mapping

- `subject_key` / `subject_display_name` = Fach
- `learning_area` = Kompetenzbereich / Lernbereich laut Lehrplan
- `competency_group` = Thema / Schwerpunkt / Teilbereich
- `competency_text` = konkrete beobachtbare Kompetenz für die App
- `competency_label` = Kurzlabel für kompakte UI

## Grundsatz für die Ableitung

Die App-Kompetenzen sollen klein genug sein, dass Laura sie mit `++`, `+`, `-`, `--` beobachten kann. Originale Lehrplanziele dürfen dafür in mehrere beobachtbare Kompetenzzeilen zerlegt werden, müssen aber im Mapping auf die Lehrplanquelle rückführbar bleiben.
