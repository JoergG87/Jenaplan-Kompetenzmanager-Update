# Isolierte PySide6-UX-Prototypen

Dieser Bereich enthält ausschließlich visuelle, nicht produktiv angebundene
Prototypen. Die Prototypen verwenden statische Beispieldaten und dürfen weder
Adapter noch Repositories, SQLite oder den produktiven Startpfad aufrufen.

## Sprint 5B1 – Beobachtungs-Arbeitsfläche

Start aus dem Projektwurzelverzeichnis:

```bash
python3 -m src.gui.observation_dialog_prototype
```

Der Speichern-Button und die Attachment-Aktion simulieren nur sichtbares
Feedback. Es werden keine Daten oder Dateien geschrieben.
