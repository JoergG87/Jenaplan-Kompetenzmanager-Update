# Jenaplan-Kompetenzmanager – Update-Metadaten

Dieses Repository veröffentlicht ausschließlich technische Metadaten für
signierte Updates des Jenaplan-Kompetenzmanagers.

- `pilot/` ist der beaufsichtigte Pilotkanal.
- `stable/` ist vorbereitet, aber nicht aktiviert.
- Updatearchive liegen als GitHub-Release-Assets und werden von Sparkle vor
  dem Entpacken mit EdDSA geprüft.

Nicht in dieses Repository gehören private Schlüssel, Zugangsdaten,
Schülerdaten, Testdaten-Backups, DMGs, Runtime-Dateien oder Support-Artefakte.
