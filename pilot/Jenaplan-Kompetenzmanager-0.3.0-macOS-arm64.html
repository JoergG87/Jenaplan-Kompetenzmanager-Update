Jenaplan-Kompetenzmanager 0.3.0 – Pilot-/Pre-Release

  • Dieses Update ist ausschließlich für den beaufsichtigten Pilotkanal unter macOS auf Apple-Silicon-Macs (arm64) bestimmt.
  • Es korrigiert den Neustart nach einer Wiederherstellung und verbessert Leistung und Bedienbarkeit.
  • Die App ist ad-hoc signiert und nicht notarisiert. macOS kann deshalb eine manuelle Gatekeeper-Freigabe verlangen.
  • Windows wird nicht unterstützt.
  • Die produktive Verschlüsselung von Fachdaten ist weiterhin deaktiviert.
  • ZIP-v1 bleibt das produktive Sicherungsformat.
